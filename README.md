## 本地查看

安装Node.js后，在仓库根目录执行：

```sh
node scripts/preview.mjs
```

打开 http://127.0.0.1:49331/ 。如果端口已经占用，可指定其他端口：

```sh
PORT=49332 node scripts/preview.mjs
```

不要通过双击HTML或`file://`访问：资源与站内入口以站点根目录为基准，需要HTTP服务。

## 发布边界

上传到GitHub仅为仓库存储，不等于网站已上线。本次没有启用GitHub Pages、配置公网域名或创建自动部署流程。

正式部署只以`dist/`作为站点根目录。内有Netlify格式的`_headers`与`_redirects`；其他托管平台需要实现等价的深层地址、真正404、缓存与响应头行为。不要直接将当前根相对地址的网站部署在GitHub项目子路径后宣称无需验证。

当前正式域名未配置，不输出虚构canonical或站点地图。域名确定后，可在保留的本地原工程通过`ZX_SITE_ORIGIN`生成域名元数据与sitemap，再同步新的静态产物。部署后还需检查HTTPS、缓存、重定向与分享抓取。
